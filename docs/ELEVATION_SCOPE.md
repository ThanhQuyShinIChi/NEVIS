# NEVIS 2.03 Elevation Scope

This document defines the boundary of Milestone B and prevents accidental implementation of Milestone C concerns.

## Core Principle

Milestone B = Topology Only

Milestone C = Physical Reality

## Included

- LevelDatum
- Node Elevation
- Pipe Elevation
- Propagation
- Y
- LT
- DT
- IN
- 集合管
- Validation
- Preview
- Apply

## Excluded

- Physical Offset
- Catalog Dimensions
- B寸法
- 差口M/L
- 立て管有効長
- Multiple Z per Port
- Hydraulic Simulation
- Physical Invert Modeling

These excluded items belong to Milestone C unless explicitly approved otherwise.
